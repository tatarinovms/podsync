# 📚 Аудиокниги в Podsync

[English](../audiobooks.md) | **Русский**

Podsync включает полноценную встроенную поддержку локальных аудиокниг, превращая директории с аудиофайлами на диске в последовательные (serial) подкаст-ленты, полностью совместимые со стандартами Apple Podcasts, Pocket Casts, Overcast и Podcast 2.0.

---

## Ключевые возможности

- **Стандарт сериалов Podcast 2.0**: Формирует теги `<itunes:type>serial</itunes:type>` и пронумерованные `<itunes:episode>N</itunes:episode>`, благодаря чему подкаст-плееры воспроизводят главы в правильном хронологическом порядке (от главы 1 до главы N).
- **Естественная сортировка глав (Natural Sort)**: Автоматически сортирует имена треков по человеческой логике (`01`, `02` ... `10`, `11`), а не по наивному алфавитному порядку (`1`, `10`, `2`).
- **Извлечение обложек из метаданных**: Автоматически извлекает встроенные изображения обложек из тегов ID3/APIC аудиофайлов, либо использует файлы `cover.jpg`, `cover.png` или `folder.jpg` из директории книги.
- **Широкий набор форматов**: Поддерживаются файлы `.mp3`, `.m4a`, `.m4b`, `.aac`, `.flac` и `.ogg`.
- **Динамическое пересканирование**: При добавлении новых глав в существующую папку количество эпизодов и метаданные обновляются при следующем сканировании без необходимости пересоздавать ленту.
- **Отсутствие нагрузки по cron**: Аудиокниги представляют собой локальные коллекции файлов на диске и не нагружают процессор фоновыми циклами опроса как YouTube-ленты; они обновляются при импорте, изменении настроек или по ручному запросу.
- **Веб-интерфейс и импорт в 1 клик**: Загрузка, управление, импорт и удаление книг прямо из консоли Web Admin.

---

## Настройка

Задайте корневую директорию для хранения аудиокниг в `config.toml` (или через переменную окружения `PODSYNC_AUDIOBOOKS_DIR`):

```toml
[audiobooks]
  dir = "/mnt/dietpi_userdata/podsync/audiobooks"
```

Пример структуры папок на сервере:

```text
/mnt/dietpi_userdata/podsync/audiobooks/
├── Solaris/
│   ├── cover.jpg
│   ├── 01 Chapter 1.mp3
│   ├── 02 Chapter 2.mp3
│   └── 03 Chapter 3.mp3
└── Dune/
    ├── 01 Part One.m4b
    └── 02 Part Two.m4b
```

## Импорт аудиокниги

### 1. Через консоль Web Admin

1. Перейдите на вкладку **Audiobooks** по адресу `/admin/`.
2. Все не привязанные к лентам папки отобразятся в списке **Unlinked Directories**.
3. Нажмите **Import** напротив нужной папки:
   - Укажите уникальный **Feed ID** (идентификатор ленты);
   - Настройте название, автора/чтеца и описание;
   - Нажмите **Import as Podcast Feed**.
4. URL ленты будет сформирован мгновенно (например, `https://rssreader.example.com/solaris.xml`).

### 2. Через загрузку файлов в веб-интерфейсе

Аудиофайлы можно загружать прямо через браузер:
- Перетащите аудиофайлы (например, `.mp3`, `.m4b`, `.m4a`) и опциональное изображение обложки (`cover.jpg`/`cover.png`) в область загрузки на вкладке **Audiobooks** (загружайте файлы напрямую; ZIP-архивы сервером автоматически не распаковываются);
- Укажите имя целевой папки книги;
- Включите **«Auto-import as Podcast feed»** для автоматического создания ленты сразу после окончания загрузки;
- **Лимит загрузки**: Поддерживается пакетная загрузка файлов объёмом до **1 ГиБ** с потоковой обработкой multipart/form-data.

### 3. Через REST API

```bash
# 1. Получить список доступных папок на диске
curl -u "admin:password" http://localhost:8080/api/v1/audiobooks/dirs

# 2. Импортировать папку как подкаст-ленту
curl -u "admin:password" -X POST http://localhost:8080/api/v1/audiobooks/import \
  -H "Content-Type: application/json" \
  -d '{
    "dir_name": "Solaris",
    "id": "solaris",
    "title": "Солярис",
    "author": "Станислав Лем",
    "description": "Классика мировой фантастики"
  }'

# 3. Загрузить треки на сервер
curl -u "admin:password" -X POST http://localhost:8080/api/v1/audiobooks/upload \
  -F "book_dir=Solaris" \
  -F "files=@chapter01.mp3" \
  -F "cover=@cover.jpg" \
  -F "auto_import=true"

# 4. Удалить папку и привязанную ленту с диска
curl -u "admin:password" -X DELETE "http://localhost:8080/api/v1/audiobooks/dirs?name=Solaris"
```

### 4. Через MCP (Model Context Protocol)

AI-ассистенты могут управлять аудиокнигами с помощью специализированных инструментов MCP:
- `list_audiobook_dirs`: получение списка директорий, количества глав, общего размера и статуса привязанной ленты.
- `import_audiobook`: `{"dir_name": "Solaris", "id": "solaris", "title": "Солярис", "author": "Станислав Лем"}`.
- `delete_audiobook_dir`: `{"dir_name": "Solaris"}` (размонтирует ленту, удаляет конфигурацию и удаляет файлы с диска).

## Удаление аудиокниги

При удалении директории аудиокниги через веб-панель или API (`DELETE /api/v1/audiobooks/dirs?name=BookName`):
1. Запрашивается подтверждение действия;
2. Размонтируется виртуальный HTTP-роут раздачи файлов;
3. Удаляется запись о ленте из `config.toml` и базы данных BadgerDB;
4. Папка с файлами безопасно удаляется с диска.
