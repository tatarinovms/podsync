# Настройка расписания через cron-выражения

[English](../cron.md) | **Русский**

Параметр `cron_schedule` позволяет настроить точное расписание проверки и скачивания обновлений для каждого подкаста.
Cron-выражение состоит из 5 полей, разделённых пробелами:

| Имя поля     | Обязательно? | Допустимые значения | Специальные символы        |
| ------------ | ------------ | ------------------- | -------------------------- |
| Минуты       | Да           | 0-59                | * / , -                    |
| Часы         | Да           | 0-23                | * / , -                    |
| День месяца  | Да           | 1-31                | * / , - ?                  |
| Месяц        | Да           | 1-12 или JAN-DEC    | * / , -                    |
| День недели  | Да           | 0-6 или SUN-SAT     | * / , - ?                  |

Значения полей месяца и дня недели регистронезависимы (`SUN`, `Sun` и `sun` эквивалентны).
Формат соответствует стандарту cron: https://ru.wikipedia.org/wiki/Cron

#### Предопределённые расписания

Вместо полного выражения можно использовать стандартные шорткаты:

| Выражение               | Описание                                    | Эквивалент    |
| ----------------------- | ------------------------------------------- | ------------- |
| `@monthly`              | Раз в месяц, в полночь первого числа         | `0 0 1 * *`   |
| `@weekly`               | Раз в неделю, в полночь между сб и вс        | `0 0 * * 0`   |
| `@daily` (или `@midnight`) | Раз в сутки, в полночь                   | `0 0 * * *`   |
| `@hourly`               | Раз в час, в начале часа                    | `0 * * * *`   |

#### Интервалы

Также можно настроить запуск с фиксированным интервалом, начиная с момента старта Podsync:

    @every <длительность>

где "длительность" — строка, поддерживаемая функцией [time.ParseDuration](https://pkg.go.dev/time#ParseDuration) в Go (например, `s`, `m`, `h`).

Например, `@every 1h30m10s` означает запуск через 1 час 30 минут 10 секунд после старта и повторение с этим интервалом.
