Команды из руководств запускаются из корня репозитория, если не указано иное.
После изменения Go-кода выполняйте `go test -race ./...`. Браузерный тест
библиотеки расположен в `tests/e2e/` и запускается отдельно:

```bash
cd tests/e2e
npm ci
npx playwright install chromium
npm test
```

На Linux для установки системных зависимостей браузера используйте
`npx playwright install --with-deps chromium`. Нужен Node.js 20 или новее.
Тест использует временный локальный сервер и подменяет API; рабочий экземпляр
Podsync не нужен. CDN-ресурсы интерфейса подменяются закреплёнными локальными
npm-пакетами; после установки зависимостей и браузера интернет не нужен. Скриншоты
сохраняются во временную папку, путь к которой выводится при запуске.
В CI тест запускается отдельной задачей **Browser tests**.

При Docker-сборке `.git/`, документация, навыки агентов, локальные `config.toml`,
`cookies.txt`, `data/`, `db/` и артефакты не входят в контекст. Конфигурация и
данные подключаются через тома. `make docker` передаёт версию и коммит в сборку;
при прямом вызове `docker build` используйте `--build-arg TAG=...` и
`--build-arg COMMIT=...`, если эти значения нужны. Без них используются `dev`
и `unknown`.
