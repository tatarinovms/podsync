# Фильтры эпизодов

[English](../filters.md) | **Русский**

Podsync поддерживает гибкую фильтрацию эпизодов по названию, описанию, длительности и дате публикации. Фильтры настраиваются индивидуально для каждого фида в секции `[feeds.<id>.filters]`.

Все фильтры объединяются по **логике «И» (AND)** — эпизод скачивается только в том случае, если удовлетворяет всем заданным условиям.

## Доступные фильтры

| Поле              | Тип    | Описание                                             |
| ----------------- | ------ | ---------------------------------------------------- |
| `title`           | string | Скачивать только эпизоды, заголовок которых совпадает с регулярным выражением |
| `not_title`       | string | Пропускать эпизоды, заголовок которых совпадает с регулярным выражением |
| `description`     | string | Скачивать только эпизоды, описание которых совпадает |
| `not_description` | string | Пропускать эпизоды, описание которых совпадает      |
| `min_duration`    | int    | Пропускать эпизоды короче N секунд                   |
| `max_duration`    | int    | Пропускать эпизоды длиннее N секунд                  |
| `min_age`         | int    | Пропускать эпизоды новее N дней                      |
| `max_age`         | int    | Пропускать эпизоды старше N дней                     |

Регулярные выражения используют [синтаксис Go regexp](https://pkg.go.dev/regexp/syntax).

---

## Примеры использования

### Исключение эпизодов по ключевым словам

Используйте `not_title` с оператором «ИЛИ» (`|`), чтобы пропускать выпуски с нежелательными словами:

```toml
[feeds.my_feed.filters]
# Пропускать стримы, ответы на вопросы и Shorts (регистронезависимо)
not_title = "(?i)(live|q&a|#shorts)"
```

### Скачивание только выпусков с определённым словом

Используйте `title`, чтобы отбирать только нужные ролики:

```toml
[feeds.my_feed.filters]
# Скачивать только обучающие ролики и руководства
title = "(?i)(tutorial|гайд|руководство)"
```

### Фильтрация по длительности

Используйте `min_duration` и `max_duration` (в секундах), чтобы отсекать слишком короткие или слишком длинные видео:

```toml
[feeds.my_feed.filters]
# Скачивать только полные выпуски (от 10 минут до 3 часов)
min_duration = 600
max_duration = 10800
```

### Исключение коротких клипов и трейлеров

Комбинация фильтра по заголовку и минимальной длительности:

```toml
[feeds.my_feed.filters]
# Исключать ролики со словами clip/trailer и всё, что короче 5 минут
not_title = "(?i)(clip|клип|тизер|trailer)"
min_duration = 300
```

### Только свежие эпизоды

Используйте `max_age` для ограничения возраста скачиваемых видео:

```toml
[feeds.my_feed.filters]
# Скачивать только эпизоды за последние 90 дней
max_age = 90
```

### Отложенная загрузка (ожидание правок автора)

Используйте `min_age`, чтобы видео скачивалось только спустя N дней после публикации:

```toml
[feeds.my_feed.filters]
# Подождать не менее 2 дней перед загрузкой (автор может исправить звук или видеоряд)
min_age = 2
```

### Фильтрация по тексту описания

```toml
[feeds.my_feed.filters]
# Скачивать только выпуски, где в описании упомянуто слово "интервью"
description = "(?i)интервью"
```

### Комбинация фильтров

Все указанные фильтры должны выполниться одновременно:

```toml
[feeds.my_feed.filters]
# Эпизоды про Go/Golang, не для начинающих, длительностью более 10 минут
title        = "(?i)(golang|go)"
not_title    = "(?i)(beginner|для новичков|101)"
min_duration = 600
```

### Точное совпадение фразы

Используйте границы слов `\b`:

```toml
[feeds.my_feed.filters]
# Только выпуски с точной фразой "полный выпуск"
title = "(?i)\\bполный выпуск\\b"
```

---

## Важные замечания

- `title` и `description` — фильтры **включения**: эпизод скачивается только при совпадении.
- `not_title` и `not_description` — фильтры **исключения**: эпизод пропускается при совпадении.
- Фильтры длительности и возраста отсекают видео вне указанных диапазонов.
- Для условий «ИЛИ» внутри поля используйте регулярные выражения (`a|b`).

## Фильтры стримов и нормализация звука

Помимо регулярных выражений, Podsync поддерживает флаги обработки на уровне фида `[feeds.<id>]`:

### Игнорирование стримов и премьер (`ignore_live`)

Позволяет предотвратить зависание и ошибки очереди загрузчика на запланированных премьерах и идущих онлайн-трансляциях:

```toml
[feeds.my_feed]
url = "https://www.youtube.com/@channel/videos"
# Автоматически пропускать активные стримы и предстоящие премьеры
ignore_live = true
```

### Нормализация громкости (`normalize_audio`)

Выравнивает звук всех выпусков под стандарт Apple Podcasts и Spotify (`-16 LUFS`, `-1.5 dB True Peak`, `11 LRA`):

```toml
[feeds.my_feed]
url = "https://www.youtube.com/@channel/videos"
format = "audio"
# Включить нормализацию звука EBU R128
normalize_audio = true
```

### Переопределение прокси для фида (`proxy`)

Позволяет направлять конкретный фид через собственный прокси либо отключать общий прокси директивой `direct`:

```toml
[feeds.vk_feed]
url = "https://vkvideo.ru/@channel"
# Прямое соединение без прокси при включенном глобальном SOCKS5
proxy = "direct"
```
