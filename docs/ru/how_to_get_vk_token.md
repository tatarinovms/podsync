# Как получить токен VK API

[English](../how_to_get_vk_token.md) | **Русский**

VK убрал создание standalone-приложений из нового портала разработчиков. Получить пользовательский токен доступа (`video`, `offline`) можно либо через официальную ссылку VK OAuth, либо через проверенный сервис-генератор:

### Способ 1: Прямая ссылка VK OAuth (oauth.vk.ru)

1. Откройте в браузере следующую ссылку авторизации:
   ```text
   https://oauth.vk.ru/authorize?client_id=2685278&scope=video,offline&redirect_uri=https://oauth.vk.ru/blank.html&display=page&response_type=token&revoke=1
   ```

2. Нажмите кнопку **«Разрешить»** (предоставляет доступ к видеозаписям и бессрочный доступ `offline`).

3. Браузер перенаправит вас на техническую страницу-заглушку. В адресной строке появится URL вида:
   ```text
   https://oauth.vk.ru/blank.html#access_token=vk1.a.XXXXXXXXXXXX...&expires_in=0&user_id=12345678
   ```

> [!NOTE]
> Текст на белой странице: *«Пожалуйста, не копируйте данные из адресной строки для сторонних сайтов...»* — это **не ошибка**, а стандартное предупреждение безопасности VK. Токен уже сформирован и находится в адресной строке.

4. Скопируйте значение `access_token` (начиная с `vk1.a...` и до `&expires_in=0`). Podsync также умеет автоматически извлекать токен, если вставить URL целиком!

### Способ 2: Через генератор vkhost.github.io

Если прямая ссылка недоступна:

1. Перейдите на [vkhost.github.io](https://vkhost.github.io).
2. Выберите плитку **Kate Mobile** (или **VK Admin**).
3. Нажмите кнопку **«Разрешить»** на странице авторизации VK.
4. Откроется страница-заглушка. Скопируйте токен доступа из адресной строки (значение от `access_token=` до `&expires_in`).

### Настройка токена в Podsync

Полученный токен можно указать несколькими способами:

1. **Через веб-панель Podsync**: откройте вкладку **«API Keys»**, вставьте токен в поле **VKVIDEO** и нажмите **«Save»**.
2. **В файле `config.toml`**:\n   ```toml
   [tokens]
   vkvideo = "vk1.a.XXXXXXXXXXXX..."
   ```
3. **Через переменную окружения**:
   ```sh
   export PODSYNC_VKVIDEO_API_KEY="vk1.a.XXXXXXXXXXXX..."
   ```
