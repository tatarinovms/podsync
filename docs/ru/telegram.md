# Telegram-бот

Необязательный бот позволяет управлять одним экземпляром Podsync из одного личного чата Telegram. Он использует long polling, поэтому публичный адрес для webhook не нужен. Команды и сообщения бота — на английском.

## Настройка

1. Создайте бота через BotFather и храните токен в секрете.
2. Включите Web Admin и откройте **Access & integrations → Telegram**.
3. Вставьте токен, при необходимости укажите **Allowed Telegram user ID** и **HTTP / SOCKS5 proxy**, включите **Enable Telegram bot** и нажмите **Save**. Podsync проверит токен через Telegram `getMe`, сохранит его в `config.toml` и сразу запустит polling — перезапуск не нужен. Файл конфигурации записывается с правами `0600`.
4. Нажмите **Connect** и в течение 10 минут отправьте показанную команду `/start <code>` боту в личном чате. Управление получит только этот аккаунт Telegram и этот чат.
5. Нажмите **Send test**, чтобы проверить доставку. **Disconnect** отвязывает владельца. Панель показывает числовой user ID текущего владельца с кнопкой копирования.

Выключение бота останавливает polling и уведомления, но сохраняет привязку и очередь доставки до следующего включения. Смена токена отвязывает текущего владельца и требует новой команды `/start <code>`. Удалить токен можно только при выключенном боте и если он хранится в `config.toml`.

### Ограничение по Telegram user ID

`allowed_user_id` — необязательный положительный числовой **user ID** Telegram (`from.id`), не `@username` и не chat ID. Значение `0` оставляет прежний режим: подключиться может любой, кому известен действующий код привязки.

Если значение задано, привязаться и пользоваться командами и кнопками сможет только этот аккаунт Telegram. Совпадающий ID сохраняет текущего владельца; другой ID отвязывает владельца, очищает активный код привязки и черновики и требует новой команды `/start`. Возврат к `0` снимает ограничение, но не восстанавливает ранее отвязанного владельца. Чужие пользователи игнорируются без пояснений, включая callback-кнопки; групповые чаты по-прежнему не поддерживаются.

Если user ID ещё неизвестен, сначала привяжите свой чат, скопируйте показанный ID и затем установите ограничение. Ошибка проверки токена, записи конфигурации или перезапуска бота откатывает работающего бота и состояние привязки к прежним настройкам.

### Прокси для Telegram

Если `api.telegram.org` заблокирован в вашем регионе, задайте `proxy` на вкладке Telegram. Поддерживаются схемы `http://`, `https://`, `socks5://` и `socks5h://`; логин и пароль можно указать в URL. Прокси используется для polling Bot API, проверки токена через `getMe` и тестовых сообщений. На загрузку лент он не влияет — для неё есть настройки прокси в Downloader. Пустое поле означает прямое подключение. Изменения применяются без перезапуска Podsync.

### Токен из окружения

`PODSYNC_TELEGRAM_BOT_TOKEN` перекрывает `[telegram].token`. Если переменная задана, Web Admin показывает **token from environment** и блокирует редактирование и удаление токена. Переключатель включения при этом сохраняется. Чтобы заменить или удалить токен из окружения, измените переменную и перезапустите Podsync, затем при необходимости сохраните настройки ещё раз.

Если процесс Podsync не может писать в `config.toml`, используйте токен из окружения или сделайте файл конфигурации доступным для записи. Ошибка проверки токена, записи конфигурации или перезапуска бота оставляет прежнюю работающую конфигурацию и показывает безопасное сообщение в интерфейсе.

## Команды

- Отправьте HTTP- или HTTPS-ссылку на медиа. Кнопками выберите Personal Feed, Audio или Video, затем качество или разрешение. Бот подтвердит постановку эпизода в очередь и сообщит его ID.
- `/status` показывает количество лент, загрузок и ошибок.
- `/errors` показывает недавние ошибки и ID для повтора.
- `/retry <feed_id> <episode_id>` ставит эпизод обычной или персональной ленты на повторную загрузку.
- `/cancel` сбрасывает незавершённый выбор; `/help` показывает команды.

Бот уведомляет о новой ошибке после завершения обновления и об исчезновении прежней ошибки. Проблемы с доставкой в Telegram не останавливают обновление лент. Неотправленные уведомления и отметки о событиях хранятся в `telegram-state.json` рядом с БД Badger. Состояние привязки и доставки не входит в переносимые бэкапы: после миграции подключите бот снова. `include_secrets=false` исключает токен бота из конфигурации в бэкапе.

Бот работает при включённом Web Admin и обычном запуске Podsync с локальным хранилищем. Он не запускается в режимах headless, бэкапа, миграции и отдельного MCP-сервера.
