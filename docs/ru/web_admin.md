# Панель веб-администрирования (Web Admin Console)

[English](../web_admin.md) | **Русский**

Podsync включает встроенную адаптивную веб-консоль управления, предназначенную для администрирования подкаст-лент, мониторинга эпизодов, быстрой подписки в 1 клик и наблюдения за состоянием системы.

Консоль полностью автономна (встроена непосредственно в бинарный файл Go) и не требует внешних окружений Node.js/npm или отдельной раздачи статических файлов.

---

## Быстрая настройка

### 1. Включение через `config.toml`

Добавьте секцию `[server.admin]` в файл `config.toml`:

```toml
[server]
port = 8080
# hostname используется для формирования RSS-ссылок и QR-кодов.
# Укажите адрес, по которому Podsync доступен с ваших устройств:
hostname = "http://192.168.1.100:8080"

[server.admin]
enabled = true
username = "admin"
password = "your-secure-password"
```

### 2. Включение через переменные окружения (Docker / Docker Compose)

Веб-панель можно настроить без редактирования `config.toml`:

```bash
PODSYNC_ADMIN_ENABLED=true
PODSYNC_ADMIN_USERNAME=admin
PODSYNC_ADMIN_PASSWORD=your-secure-password
```

Пример для `docker-compose.yml`:

```yaml
services:
  podsync:
    image: ghcr.io/tatarinovms/podsync:latest
    container_name: podsync
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      - PODSYNC_ADMIN_ENABLED=true
      - PODSYNC_ADMIN_USERNAME=admin
      - PODSYNC_ADMIN_PASSWORD=your-secure-password
    volumes:
      - ./config.toml:/app/config.toml
      - ./data:/app/data
      - ./db:/app/db
```

### 3. Переопределение через флаги CLI

Настройки веб-панели можно принудительно переопределить при запуске:

```bash
# Принудительно включить веб-панель (/admin) независимо от config.toml / ENV:
./bin/podsync --config config.toml --admin

# Полностью отключить веб-панель (/admin):
./bin/podsync --config config.toml --no-admin
```

> [!NOTE]
> Флаги CLI (`--admin` / `--no-admin`) имеют наивысший приоритет и переопределяют как переменные окружения (`PODSYNC_ADMIN_ENABLED`), так и настройки в `config.toml` (`[server.admin] enabled = ...`).

## Доступ к веб-панели

Откройте веб-браузер и перейдите по адресу:
```text
http://<хост-podsync>:<порт>/admin/
```

Войдите, используя настроенные имя пользователя и пароль.

## Возможности и функции

### 1. Подкаст-ленты и подписка в 1 клик
- **Карточки каналов**: просмотр всех каналов с обложками высокого разрешения, бейджами провайдеров (VK Video, YouTube, Rutube, Vimeo, SoundCloud, Twitch), счётчиками эпизодов и занятым местом на диске.
- **Копирование RSS-ссылки**: копирование прямого адреса ленты (`http://<host>:<port>/<feed_id>.xml`) в буфер обмена в один клик.
- **Генератор QR-кодов**: кнопка QR-кода на каждой карточке отображает код на экране для мгновенной подписки через камеру смартфона.
- **Диплинки для подкаст-плееров**: прямые ссылки для подписки в популярных приложениях:
  - **Apple Podcasts** (`podcast://...`)
  - **Pocket Casts** (`pktc://subscribe/...`)
  - **Overcast** (`overcast://...`)

### 2. Управление лентами
- **Добавление ленты**: нажмите **+ Add Feed** для регистрации нового канала, пользователя или плейлиста (VK Video, YouTube, Rutube, Vimeo и др.).
  - Автоопределение Feed ID из URL.
  - Настройка формата (`video`, `audio`), качества (`high`, `low`), периодичности обновления и фильтров заголовков.
  - **Мгновенная синхронизация**: созданные ленты сразу сохраняются в `config.toml`, добавляются в расписание cron и ставятся в очередь загрузки.
- **Удаление ленты**: удаление ленты из памяти и `config.toml` с возможностью очистки медиафайлов с диска.
- **Ручное обновление («Update Now»)**: принудительный запуск обновления ленты без ожидания следующего цикла cron.

### 3. Просмотр эпизодов и повтор ошибок
- Кнопка **Episodes** открывает список всех найденных выпусков.
- Статусные бейджи: `Downloaded` (с размером файла и датой), `New` или `Error`.
- **Повтор неудачных загрузок**: если выпуск не скачался (например, из-за временного сетевого сбоя или лимита запросов), кнопка **Retry** сбрасывает статус и отправляет его на повторное скачивание.

### 4. Управление токенами и API-ключами
- Вкладка **API Keys** отображает токены для всех провайдеров:
  - **VK Video** (`PODSYNC_VKVIDEO_API_KEY` / `PODSYNC_VK_API_KEY`)
  - **YouTube** (`PODSYNC_YOUTUBE_API_KEY`)
  - **Rutube** (`PODSYNC_RUTUBE_API_KEY`, опционально — для публичных видео ключ не требуется)
  - **Vimeo** (`PODSYNC_VIMEO_API_KEY`)
  - **SoundCloud** (`PODSYNC_SOUNDCLOUD_API_KEY`)
  - **Twitch** (`PODSYNC_TWITCH_API_KEY`)
- В целях безопасности ключи маскируются (`••••••••`).
- Добавление и изменение ключей прямо из интерфейса с автоматическим сохранением в `config.toml`.

### 5. Состояние системы и метрики
- Вкладка **System** отображает параметры экземпляра в реальном времени:
  - **Дисковое пространство**: общий, занятый и свободный объём на накопителе (`data_dir`) с индикатором заполнения.
  - **Оперативная память**: объём RAM, выделенный процессу Podsync.
  - **Аптайм сервера**: время непрерывной работы сервиса.
  - **Проверка зависимостей**: контроль наличия и доступности `yt-dlp` и `ffmpeg` в системном `$PATH`.

### 6. Настройка загрузчика и Cookies (yt-dlp)
- Вкладка **Downloader & Cookies** решает проблемы с защитой от ботов:
  - **Обход блокировок YouTube**: устранение ошибки `Sign in to confirm you're not a bot. Use --cookies-from-browser or --cookies for the authentication`.
  - **Cookies в формате Netscape (`cookies.txt`)**: вставка или загрузка файлов cookies прямо в интерфейс с сохранением в `data/cookies.txt`.
  - **Cookies из браузера**: на локальных установках можно выбрать установленный браузер (Chrome, Firefox, Safari, Brave, Edge) для автоматического извлечения сессионных cookies.
  - **HTTP/SOCKS5 прокси**: настройка прокси-сервера (`--proxy`) для трафика yt-dlp.
  - **Параметры движка**: таймаут скачивания и автообновление yt-dlp каждые 24 часа.
  - **Инструмент проверки URL**: тестирование извлечения метаданных yt-dlp по любому URL с текущими cookies и прокси.

## Таблица эндпоинтов REST API

Консоль работает на базе JSON REST API, который также можно использовать для автоматизации.
Все эндпоинты `/api/v1/` требуют авторизации (Session Cookie или HTTP Basic Auth), кроме публичных методов аутентификации (`/api/v1/auth/status`, `/api/v1/auth/login`, `/api/v1/auth/logout`).

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/api/v1/auth/status` | `GET` | Получить текущий статус аутентификации |
| `/api/v1/auth/login` | `POST` | Выполнить вход и получить сессионную cookie |
| `/api/v1/auth/logout` | `POST` | Завершить сессию пользователя |
| `/api/v1/auth/password` | `POST` | Изменить пароль администратора (требуется текущий пароль) |
| `/api/v1/system/errors` | `GET` | Список ошибок загрузки с очищенными диагностическими причинами и рекомендациями |
| `/api/v1/system/recent` | `GET` | Список последних успешно скачанных выпусков |
| `/api/v1/system/status` | `GET` | Общий срез состояния (расписание синхронизации, загрузки за 24ч, активные ошибки) |
| `/api/v1/feeds` | `GET` | Список всех настроенных лент со статистикой |
| `/api/v1/feeds` | `POST` | Добавить новую ленту |
| `/api/v1/feeds/status` | `GET` | Быстрый статус лент в памяти (состояние: idle, queued, running; last_error, время обновления) |
| `/api/v1/feeds/update` | `POST` | Запустить параллельное обновление всех настроенных лент сразу |
| `/api/v1/feeds/{id}` | `GET` | Детальная информация о ленте и список эпизодов |
| `/api/v1/feeds/{id}` | `PUT` | Обновить конфигурацию ленты (cron, формат, качество, page_size, хранение, язык) |
| `/api/v1/feeds/{id}` | `DELETE` | Удалить ленту (опционально: `?delete_files=true` для удаления файлов с диска) |
| `/api/v1/feeds/{id}/update` | `POST` | Запустить немедленное обновление конкретной ленты |
| `/api/v1/feeds/{id}/episodes/{ep_id}/retry` | `POST` | Сбросить ошибку эпизода для повторного скачивания |
| `/api/v1/tokens` | `GET` | Получить маскированные токены для всех провайдеров |
| `/api/v1/tokens` | `POST` | Сохранить или обновить токены провайдера |
| `/api/v1/tokens` | `DELETE` | Удалить токен по индексу или очистить все токены провайдера |
| `/api/v1/audiobooks/dirs` | `GET` | Список папок аудиокниг, количество глав, объём и статус привязанной ленты |
| `/api/v1/audiobooks/import` | `POST` | Импортировать локальную папку в серийную ленту Podcast 2.0 |
| `/api/v1/audiobooks/upload` | `POST` | Загрузить аудиофайлы и обложку книги через multipart/form-data |
| `/api/v1/audiobooks/dirs` | `DELETE` | Удалить папку аудиокниги и связанную ленту с диска |
| `/api/v1/audiobooks/config` | `GET` | Получить путь к корневой директории аудиокниг и статус |
| `/api/v1/system/logs` | `GET` | Запрос системных логов с фильтрацией по уровню, тексту или feed_id |
| `/api/v1/system/logs` | `DELETE` | Очистить буфер логов в оперативной памяти |
| `/api/v1/system/logs/level` | `GET` | Получить текущий уровень логирования сервера (info, debug, warn, error) |
| `/api/v1/system/logs/level` | `POST` | Изменить уровень логирования на лету (info, debug, warn, error) |
| `/api/v1/system/logs/download` | `GET` | Скачать полный файл логов сервера в текстовом формате |
| `/api/v1/mcp/config` | `GET` | Получить конфигурацию для подключения MCP-клиентов по stdio и SSE |
| `/api/v1/system` | `GET` | Метрики системы, использование диска и проверка зависимостей |
| `/api/v1/downloader` | `GET` | Конфигурация загрузчика yt-dlp, статус cookies и прокси |
| `/api/v1/downloader` | `POST` | Обновить параметры загрузчика (таймаут, прокси, браузер, автообновление) |
| `/api/v1/downloader/cookies` | `GET` | Получить содержимое установленного файла cookies.txt |
| `/api/v1/downloader/cookies` | `POST` | Сохранить или загрузить новый файл cookies.txt формата Netscape |
| `/api/v1/downloader/cookies` | `DELETE` | Очистить и удалить установленный файл cookies.txt |
| `/api/v1/downloader/test` | `POST` | Тестировать извлечение по URL с текущими настройками cookies и прокси |
