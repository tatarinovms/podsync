API Keys Configuration

API keys are used to query video and playlist metadata. If a key is defined via an environment variable (ENV), it takes the highest priority.

Instructions
  • VK Video:
    vkhost.github.io (select Kate Mobile and click "Allow")
  • YouTube: Google Cloud Console → YouTube Data API v3
  • Vimeo: Developer App Access Token
  • Twitch: Twitch Developer Console (ID:SECRET)
VK Tip: After confirming permissions, a blank page will open. The security warning "Please do not copy data from the address bar..." is not an error, but a standard VK notice. You can copy the entire URL from your browser's address bar (or just the token) — Podsync will automatically extract the token for you!

Configure yt-dlp downloader engine, cookies (to bypass YouTube bot checks and age-gates), and proxy settings.

yt-dlp Ready ffmpeg Ready
Why are cookies needed? YouTube frequently blocks downloads from servers or cloud instances with the error:
ERROR: [youtube] Sign in to confirm you’re not a bot. Use --cookies-from-browser or --cookies for the authentication.
Exporting cookies from your browser (while logged into YouTube) and uploading or pasting them below allows yt-dlp to download restricted videos and playlists seamlessly.
