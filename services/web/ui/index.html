API Keys Configuration

API keys are used to query video and playlist metadata. If a key is defined via an environment variable (ENV), it takes the highest priority.

Instructions
  • VK Video:
    vkhost.github.io (recommended — select Kate Mobile and click "Allow")
    or direct OAuth link
  • YouTube: Google Cloud Console → YouTube Data API v3
  • Vimeo: Developer App Access Token
  • Twitch: Twitch Developer Console (ID:SECRET)
VK Tip: After confirming permissions, a blank page will open. The security warning "Please do not copy data from the address bar..." is not an error, but a standard VK notice. Copy the token directly from your browser's address bar (value between #access_token= and &expires_in). If the direct link encounters gateway issues, use vkhost.github.io.
